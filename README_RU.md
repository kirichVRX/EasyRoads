## 🌟 О проекте

**EasyRoads** кардинально меняет подход к строительству дорог в Minecraft. Забудьте о долгой и рутинной расстановке блоков вручную или некрасивых ломаных линиях под прямыми углами! EasyRoads позволяет проектировать реалистичные, плавные шоссе, городские улицы, горные серпантины и просёлочные тропы с помощью **трехмерных кривых Безье (3D Bézier curves)** и интерактивного внутриигрового редактора.

Оценивайте будущую трассу в реальном времени с помощью 3D-гизмо, настраивайте высоту подъемов и радиусы поворотов, выбирайте структуру слоев и дорожных профилей, и стройте готовую дорогу нажатием одной клавиши.

## ✨ Возможности

- 🛣️ **3D геометрия кривых Безье**: Плавные повороты, скоростные дуги шоссе и аккуратные переходы высоты без угловатых ступенек.
- 🎯 **Интерактивный редактор в игре (Edit Mode)**:
  - **Инструмент «Добавить» (Add)**: Ставьте опорные точки трассы прямо по ландшафту щелчком мыши (ЛКМ).
  - **Инструмент «Выбрать» (Select)**: Выбирайте существующие точки для контроля и редактирования.
  - **Инструмент «Двигать» (Adjust)**: Точное позиционирование точки в 3D (высота $Y$ с помощью колесика мыши, смещение в плоскости $XZ$ стрелками или WASD).
  - **Инструмент «Удалить» (Delete)**: Быстрое удаление лишних точек прямо в процессе работы.
- 👁️ **Визуализация в реальном времени (3D Gizmo Preview)**: Вы сразу видите точную траекторию полотна, ширину и наклон дороги до установки блоков в мир.
- 🎨 **Студия пресетов дорог (Preset Studio)**:
  - Настройка многослойных профилей (асфальтовое покрытие, гравийное основание/подушка, бордюры, тротуары, разметка).
  - Быстрое переключение и сохранение собственных стилей дорог.
- ↩️ **Безопасная система отмены (Undo)**: Промахнулись или построили трассу не там? Команда отмены аккуратно вернет исходный ландшафт без лишнего мусора и дыр.
- ⚡ **Оптимизированная серверная вокселизация**: Быстрая генерация блоков, рассчитанная на плавный TPS сервера.

## 🎮 Управление и горячие клавиши

Все клавиши можно переназначить в настройках игры: **Настройки $\rightarrow$ Управление $\rightarrow$ Назначение клавиш**:

| Клавиша | По умолчанию | Описание |
| :--- | :---: | :--- |
| **Режим редактирования** | `F7` | Вход / выход из режима создания дорог |
| **Студия пресетов** | `Caps Lock` | Открыть GUI для выбора материалов и стилей дороги |
| **Построить дорогу (Финализация)** | `Enter` | Сгенерировать блоки вдоль активной кривой |
| **Поставить опорную точку** | `Левый клик (ЛКМ)` | Поставить новую точку на земле (в режиме «Добавить») |
| **Высота точки ($Y$)** | `Колесико мыши` | Изменить высоту выбранной точки (в режиме «Двигать») |
| **Горизонтальное смещение ($XZ$)** | `Стрелки` / `WASD` | Точная подстройка точки по координатам $X$ и $Z$ |

## ⌨️ Команды

| Команда | Уровень прав | Описание |
| :--- | :---: | :--- |
| `/road undo` | OP (Уровень 2) | Отменяет последнюю построенную дорогу и восстанавливает ландшафт |
| `/road clear` | OP (Уровень 2) | Очищает активные точки трассы и режим предпросмотра |
| `/road stats` | OP (Уровень 2) | Выводит статистику текущего графа дорожной сети |
| `/road test` | OP (Уровень 2) | Создает тестовый отрезок дороги для проверки |

## 🛠️ Студия пресетов дорог

Нажмите `Caps Lock` во время игры, чтобы открыть **Road Preset Studio**:
- Выбирайте готовые стили (шоссе, городская улица, деревенская дорожка).
- Задавайте ширину проезжей части и тротуаров.
- Подбирайте палитру блоков для дорожного основания, асфальта, линий разметки и ограждений.

## 💻 Сборка из исходников

### Требования
- **Java 21** или новее
- **Git**

### Инструкция по сборке
Склонируйте репозиторий и соберите проект через Gradle:

```bash
git clone https://github.com/kirichVRX/EasyRoads.git
cd EasyRoads

# В Windows:
.\gradlew build

# В Linux / macOS:
./gradlew build
```

Скомпилированный файл мода (`.jar`) будет находиться в папке `build/libs/`.
