## 🌟 О проекте

**EasyRoads** создан специально для строителей городов, картоделов и масштабных проектов, чтобы ускорить создание дорожной сети вплоть до **10 раз**. Больше никакой монотонной укладки тысяч блоков вручную и кривых ступенек на склонах!

Проектируйте трассы с помощью математически плавных **3D-кривых Безье**, оценивайте изгиб и наклон через интерактивные 3D-гизмо и генерируйте дорогу нажатием одной кнопки.

---

## ⚡ Преимущества для градостроителей

- 🏙️ **Масштабное строительство**: Легко связывайте города дорогами, возводите многополосные развязки и горные серпантины за считанные минуты.
- 📈 **Ускорение работы в 10 раз**: Поставьте опорные точки, скорректируйте высоту и нажмите Enter.
- 🛣️ **Идеально плавные 3D-кривые**: Забудьте про грубые лестницы и резкие повороты под 90°.
- 🎯 **Интерактивный 3D-редактор (`F7`)**: Расстановка точек кликом мыши, регулировка высоты колесиком мыши (`Mouse Wheel`), смещение стрелками или WASD.
- 🎨 **Студия пресетов (`Caps Lock`)**: Готовые и настраиваемые профили полотна (асфальт, подушка из гравия, бордюры, тротуары, разметка).
- ↩️ **Безопасная отмена (`/road undo`)**: Мгновенно отменяет построенный сегмент и аккуратно восстанавливает рельеф.

## 🎮 Управление и горячие клавиши

| Клавиша | По умолчанию | Описание |
| :--- | :---: | :--- |
| **Режим редактора** | `F7` | Вход / выход из режима создания дорог |
| **Студия пресетов** | `Caps Lock` | Открыть меню стилей и материалов дороги |
| **Построить дорогу** | `Enter` | Моментальная генерация блоков вдоль кривой |
| **Поставить точку** | `Левый клик (ЛКМ)` | Поставить контрольную точку на земле |
| **Высота точки ($Y$)** | `Колесико мыши` | Изменить высоту выбранной точки |
| **Смещение ($XZ$)** | `Стрелки` / `WASD` | Сдвинуть точку по горизонтали |

## ⌨️ Команды

| Команда | Уровень прав | Описание |
| :--- | :---: | :--- |
| `/road undo` | OP (Уровень 2) | Отменяет последнюю дорогу и восстанавливает рельеф |
| `/road clear` | OP (Уровень 2) | Очищает активные точки трассы |
| `/road stats` | OP (Уровень 2) | Показывает статистику текущего графа дорог |
| `/road test` | OP (Уровень 2) | Создает тестовый отрезок дороги |

## 🛠️ Студия пресетов дорог

Нажмите `Caps Lock` во время игры, чтобы открыть **Road Preset Studio**:
- Выбор стилей: шоссе, городские улицы, проселочные дороги.
- Настройка ширины проезжей части и тротуаров.
- Палитра блоков для подушки, асфальта, разметки и бордюров.

## 💻 Сборка из исходников

```bash
git clone https://github.com/kirichVRX/EasyRoads.git
cd EasyRoads

# В Windows:
.\gradlew build

# В Linux / macOS:
./gradlew build
```

Скомпилированный `.jar` файл будет в папке `build/libs/`.
